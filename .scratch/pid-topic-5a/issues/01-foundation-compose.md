# 01: Foundation dan Compose

**What to build:** Proyek Topik 5A dapat dibuat ulang dari folder baru dengan struktur source yang jelas, `.env.example`, README awal, dan konfigurasi Docker Compose untuk seluruh stack.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Struktur final mengikuti pola `src/`, `docker-compose.yml`, `.env.example`, dan README.
- [ ] Compose mendefinisikan MQTT, Kafka, MongoDB, MySQL, Spark, Airflow, dan dashboard.
- [ ] `docker compose up` memulai semua container dari README.
- [ ] Tidak ada volume database atau virtual environment yang dikumpulkan.
